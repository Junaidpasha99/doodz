How to auto-draw an image on Instagram doodle

Quick answer: install Doodz on Android, enable its Accessibility permission, send your picture in an Instagram chat, select the same picture in the app, choose the drawing area and tap Start. Hyper Doodle adds a 2-dot calibration first.

Standard mode (fast, single colour)

  1. Upload your image in the app.
  2. Select the area to draw.
  3. Select the brush.
  4. Tap Start.

Hyper Doodle (detailed, multicolour)

  1. Send the picture in an Instagram chat and select the same picture in Doodz.
  2. Drag and resize the box on a screenshot to set the drawing area.
  3. Calibrate with 2 dots: dot 1 on Instagram's colour picker; then select the picker and place dot 2 on the brush's rest point in the middle of the screen. Deselect the picker.
  4. Tap Start and let it paint.

Tips for better results

  • Choose clear images with strong shapes and contrast, such as logos, portraits and bold artwork.
  • Check the preview for colours, size and line count before the first stroke.
  • If the drawing looks off, redo the 2-dot calibration and re-check the drawing area.
  • Hyper Doodle can only use the colours Instagram offers, so expect a palette-based look.
